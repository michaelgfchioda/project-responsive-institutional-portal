<h2> Sobre o Projeto ℹ️ </h2>
<p>
  Este projeto é um portal institucional responsivo genérico que foi desenvolvido sem nenhuma linguagem de programação (como JavaScript, Python, PHP) para integração com Back-End, SGBD ou implementar qualquer responsividade para o site. Usando somente <strong> HTML (HyperText Markup Language), CSS (Cascading Style Sheets), e o Framework Boostrap, importado via CDN </strong>, fui capaz de criar um site totalmente responsivo para uma instituição de cursos fictícia que inventei e nomeei de Instituição Michael Chioda. Graças ao Boostrap, pude otimizar muito tempo de implementação com código de CSS puro para "modernizar" e deixar o site mais bonito, da forma que eu queria, além de permitir que ele se ajuste automaticamente para diferentes tamanhos de tela, se adaptando facilmente a telas de diferentes tipos de dispositivos, como celulares, tablets, notebooks e computadores.
</p>
